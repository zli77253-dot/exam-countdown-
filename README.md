# 考试倒计时

中文手机端考试日历，纯 HTML/CSS/JavaScript，无需构建。

## 功能
- 月历与考试日期标记
- 自动计算剩余天数
- 添加、编辑、删除考试
- 考试数据保存在当前浏览器 localStorage

## 开启 GitHub Pages
1. 打开仓库 Settings → Pages。
2. Build and deployment 选择 Deploy from a branch。
3. Branch 选择 main，目录选择 /(root)，点击 Save。
4. 等待部署后访问 https://zli77253-dot.github.io/exam-countdown-/

注意：数据仅保存在当前浏览器，不会自动跨设备同步。
